

# POTENTIOMETER-BASED-ADC-AND-PWM-CONTROL-WITH-GIT

## AIM:
To analyse the relationship between potentiometer position, ADC output, and LED brightness by controlling LED intensity using a potentiometer, and to manage the source code using Git.

---

## Apparatus Required

| S. No. | Apparatus / Software | Specification |
|:---:|---|---|
| 1 | Development Board | ADC and PWM supported |
| 2 | Potentiometer | Variable analog input |
| 3 | LED | Standard LED |
| 4 | Resistor | Current limiting |
| 5 | Jumper Wires | Circuit connection |
| 6 | USB Cable | Programming and communication |
| 7 | Computer/Laptop | Windows |
| 8 | VS Code | Source code and Git management |
| 9 | Git | Version control |
| 10 | GitHub/GitLab | Remote repository |
| 11 | Microcontroller IDE/SDK | Required development environment |

---

## Procedure

1. Connect the potentiometer to the ADC input pin of the development board.
2. Connect the LED to a PWM-supported GPIO pin.
3. Configure the ADC and PWM modules.
4. Develop the program to read the potentiometer position using the ADC.
5. Map the ADC output range to the PWM duty-cycle range.
6. Use the PWM duty cycle to control the LED brightness.
7. Build and compile the program.
8. Flash the program to the development board.
9. Rotate the potentiometer gradually and observe the ADC values and LED brightness.
10. Compare the ADC readings with the observed brightness levels.
11. Open the project in VS Code and stage the source-code changes using Git.
12. Commit the completed program with a suitable commit message.
13. Push the committed changes to the remote Git repository.
14. Verify the updated files in the remote repository.
